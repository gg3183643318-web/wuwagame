# 共鸣者：夜航试炼

这是一个纯 HTML5 Canvas 的横版动作 Demo，不需要 Maven、Node 依赖或构建步骤。当前版本以本地游玩为目标，使用工作区里的菲比、弗洛洛三视图素材，并在浏览器运行时自动裁切侧面图、去除白底。

## 运行

在当前目录执行：

```bash
python3 -m http.server 8090
```

然后打开 <http://127.0.0.1:8090/>。

## 操作

单人模式使用菲比：

- `A / D`：左右移动
- `W`：跳跃
- `J`：普攻（只能命中地面怪）
- `K / L`：两个技能（可以命中飞行怪）
- `I`：大招（可以命中飞行怪）

双人模式增加弗洛洛：

- `← / →`：左右移动
- `↑`：跳跃
- `1`：普攻（只能命中地面怪）
- `2 / 3`：两个技能（可以命中飞行怪）
- `4`：大招（可以命中飞行怪）

目标是击败 20 个残响并消灭潮核。队友倒地时，另一名角色靠近并按跳跃或普攻键可以救援。
