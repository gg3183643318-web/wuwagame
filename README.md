# 共鸣者：夜航试炼

这是一个纯 HTML5 Canvas 的横版动作 Demo，不需要 Maven、Node 依赖或构建步骤。当前版本以本地游玩为目标，使用工作区里的菲比、弗洛洛三视图素材，并在浏览器运行时自动裁切侧面图、去除白底。

`参考素材/wiki官方/` 保存了从库街区公开角色页下载的菲比、弗洛洛官方图鉴素材，来源和用途记录在其中的 `SOURCES.md`。这些素材只用于本地非商业原型参考。

## 运行

在当前目录执行：

```bash
python3 -m http.server 8090
```

然后打开 <http://127.0.0.1:8090/>。

## 操作

点击「单人开始」后，选择菲比或弗洛洛，再确认出战。单人只显示所选角色的虚拟按键，也可以使用键盘；角色卡和确认按钮支持 Tab、Enter / 空格，Escape 返回模式选择。双人合作会直接进入两人关卡。

菲比（单人 / 双人）：

- `A / D`：左右移动
- `W`：跳跃
- `J`：普攻（只能命中地面怪）
- `K / L`：两个技能（可以命中飞行怪）
- `I`：大招（可以命中飞行怪）

弗洛洛（单人 / 双人）：

- `← / →`：左右移动
- `↑`：跳跃
- `1`：普攻（只能命中地面怪）
- `2 / 3`：两个技能（可以命中飞行怪）
- `4`：大招（可以命中飞行怪）

目标是击败 20 个残响并消灭潮核。队友倒地时，另一名角色靠近并按跳跃或普攻键可以救援。

普通敌人每击败 4 个会掉落一个绿色血包，角色靠近后自动回复 30 点生命。攻击会显示方向光效，地面怪的投射物命中高度也已修正。
